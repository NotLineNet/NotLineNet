Кодовая часть проекта пишется на Cursor!!!

"Not stuffy dungeon"

    Пошаговый тактический roguelike-прототип на Godot. Ранний этап, подготовлен для демонстрации и питча.

Обзор:

    Not stuffy dungeon — компактная пошаговая roguelike-игра с фокусом на чёткий игровой цикл, процедурную генерацию уровней и осмысленный выбор игрока, а не на перегруженную механику.
    Игроки по очереди тратят очки действий (ОД), перемещаясь по процедурно сгенерированному подземелью из тайлов, сталкиваются с монстрами и стремятся достичь финального целевого тайла.
    Проект активно развивается и позиционируется как прототип / vertical slice, подходящий для показа, сбора фидбэка и дальнейших обсуждений.
    Ключевые особенности
    Пошаговый тактический геймплей (до 3 игроков, ходят по очереди)
    Система очков действий (3 ОД в день, тратятся на перемещение)
    Процедурное тайловое подземелье с гарантированной достижимостью цели
    Цикл день / ночь, влияющий на состояние игры и монстров
    Структурированная боевая система на основе Battle State Machine
    Кости (dice) как источник риска и напряжения в бою

Технологии:

    Движок: Godot 4.x
    Язык: GDScript
    Платформа: PC (Windows)

Процесс разработки:

    Активное написание кода и итерации через Cursor (AI‑ассистированный IDE)
    Упор на быстрый прототипинг и рефакторинг
    Проект разрабатывается одним инди‑разработчиком. Я не сеньор‑профессионал, а скорее начинающий энтузиаст, однако проект ведётся с продакшн‑мышлением и акцентом на архитектурную чистоту.

Архитектура (кратко):

    GameManager — центральная оркестрация состояний игры
    TurnStateMachine — логика ходов игроков
    BattleStateMachine — фазы и переходы боя
    LevelManager — процедурная генерация и граф тайлов
    State Machine’ы вынесены отдельно от UI, что упрощает расширение, поддержку и дальнейший рост проекта.
